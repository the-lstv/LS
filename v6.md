## Upcoming release
LS v6 is coming sometime soon (in 2026)!
This will feature a huge refactor of the whole codebase, a rethink of the structure, and many optimizations/features, new UI system & cleaner code.

Documentation will be made along with the development so it should finally be here & it will be the first production-ready release made to "just work" out of the box so that anyone can use it. Don't worry, the simplicity will be kept.


## Planned features
- Updated UI system
  - Soldified API & components
  - Layout system
  - Dual accents
  - Contrast slider
  - LS.View, LS.List, LS.Workspace, LS.Patchbay and more
  - Dynamic animations & flow
- Data flow system
- Faster & lighter
- New animation system
- Completely new rendering engine (LS.GL), removing PIXI.js dependency, many new graphics features
- 
- Deprecate global ls-* attributes
