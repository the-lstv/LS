# What's LS?
LS is a lightweight, dependency-free frontend framework for building fast, accessible interfaces in vanilla JS/CSS, from landing pages to full-featured complex applications.<br>

- <ls:icon lightning /> Fast and lightweight: ~1.5KB gzipped
- <ls:icon accessibility /> Accessibility-first: built with accessibility in mind, and includes features to enhance it
- <ls:icon palette /> Customizable: supports theming and customization to fit your design needs
- <ls:icon code /> Developer-friendly: simple API and easy to use
